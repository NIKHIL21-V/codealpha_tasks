# 📧 Python Email Extractor — CodeAlpha Task 3

## 📌 Project Overview

The Python Email Extractor is a simple automation tool that identifies email addresses in a text file and saves the unique addresses into a separate output file.

## ✨ Features

* Extract email addresses using regular expressions.
* Remove duplicate email addresses.
* Save extracted addresses to a text file.
* Count total and unique email addresses.
* Handle missing files and file-related errors.

## 🛠️ Technologies Used

* Python
* `re` — Regular expressions
* `os` — File existence checking
* File handling
* Exception handling

## 📂 Project Structure

```text
CodeAlpha_Task3_Email_Extractor/
├── email_extractor.py
├── input.txt
├── extracted_emails.txt
└── README.md
```

## ▶️ How to Run

1. Install Python 3 if it is not already installed.
2. Open a terminal in the project directory.
3. Run:

```bash
python email_extractor.py
```

4. Enter the input and output filenames when prompted.
5. Open the output file to view the extracted email addresses.

# 📈 Stock Portfolio Tracker

**CodeAlpha Python Programming Internship — Task 2**

## 📌 Project Overview

A simple Python application that calculates stock investment values using predefined stock prices.

## ✨ Features

* View available stocks and prices.
* Add stocks and quantities to a portfolio.
* Calculate individual investment values.
* Display total investment value.
* Save portfolio data to a CSV file.

## 🛠️ Technologies Used

* Python 3
* Dictionaries
* Loops and conditional statements
* User input and output
* Arithmetic operations
* CSV file handling

## 💵 Example Stock Prices

| Stock | Price per Share |
| ----- | --------------: |
| AAPL  |            $180 |
| TSLA  |            $250 |

*These are example prices, not live market prices.*

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the Task 2 folder.
4. Run:

```bash
python stock_tracker.py
```

5. Follow the on-screen menu.
